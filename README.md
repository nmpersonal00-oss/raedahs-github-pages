# Put the full night garden on GitHub Pages — no code, no installs

1. Create a new **public** GitHub repository called `raedahs-little-world`.
2. Open this folder and drag **every file inside it** into the new repository:
   `index.html`, `og.png`, and `.nojekyll`.
3. In that GitHub repository, click **Settings → Pages**. Under **Build and
   deployment**, choose **Deploy from a branch**, choose **main**, choose
   **/(root)**, and click **Save**.

That is all. GitHub will show the website link at the top of the Pages screen
after it finishes. No Cloudflare, no terminal, no commands.

This is the full dark cherry-blossom site: glowing tree links, five different
lo-fi loops, long randomized word-search packs, letters, a GIF-filled favorites
wall, and a 30-card “guess that person” matching game. Every matching card is
a real moving GIF — no emoji placeholders. There is no crossword.

Keep `index.html` and `og.png` together in the top level of the repository.
